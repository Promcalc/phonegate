# Установка и проверка Phonegate

Приложение ставится вручную (sideload) и работает без root. Всё, что связано со звонками,
опирается на публичные API Android, поэтому часть шагов зависит от прошивки — смотрите раздел
«Что проверить на телефоне».

## 1. Требования

| Что | Значение |
|---|---|
| Android | 8.0 (API 24) и выше как минимум; реально проверять на 14–16 |
| Место | ~20 МБ + записи разговоров (`files/records`) |
| Интернет | нужен для обмена с сервером; допускается HTTP (`usesCleartextTraffic`) |
| Права | выдаются на экране «Доступ» |

## 2. Сборка

```bash
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"   # Windows: JDK из Android Studio
./gradlew :app:assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

Релизная сборка подписывается ключом из `keystore.properties` в корне проекта, а если файла
нет — отладочным ключом. Для ручной установки этого достаточно. Свой ключ:

```properties
# keystore.properties (в репозиторий не попадает, добавлен в .gitignore)
storeFile=../phonegate.jks
storePassword=...
keyAlias=phonegate
keyPassword=...
```

Отладочная сборка для быстрой проверки: `./gradlew :app:assembleDebug`, файл —
`app/build/outputs/apk/debug/app-debug.apk`.

Модульные тесты: `./gradlew :app:testDebugUnitTest`.

## 3. Установка

По кабелю:

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

Без кабеля: скопировать APK на телефон, открыть любым файловым менеджером и разрешить
установку из неизвестных источников.

## 4. Первый запуск

1. Приложение открывается на вкладке **«Доступ»** (пока не выданы нужные разрешения).
2. Нажать **«Выдать разрешения»** и согласиться со всеми запросами. Отказ хотя бы в одном
   ломает часть сценариев:
   - «Чтение SMS» / «Журнал вызовов» — данные для отчёта;
   - «Отправка SMS» / «Звонки» — выполнение команд сервера;
   - «Ответ на звонки» — снятие трубки на входящем;
   - «Микрофон» — запись ответа абонента;
   - «Состояние телефона» — определение SIM и слежение за звонком;
   - «Уведомления» — постоянное уведомление о работе процесса.
3. Выдать особый доступ:
   - **Свободная работа в фоне** — исключить приложение из оптимизации батареи;
   - **Точные будильники** — чтобы задачи исполнялись в назначенное время.
4. На прошивках Xiaomi, Huawei, Samsung, Oppo и подобных дополнительно включить автозапуск
   и снять ограничения фоновой работы в настройках самой прошивки: системные разрешения
   Android не отменяют их собственные ограничения.

## 5. Настройки

Вкладка **«Настройки»**:

| Поле | Что значит |
|---|---|
| URL обмена | Приём отчёта и выдача команд |
| URL отчёта об исходящих | Отчёт о том, что приложение сделало само; пусто — не отправлять |
| Имя и значение заголовка авторизации | Пустое имя — запросы без авторизации |
| Номер первой / второй SIM | Ключ отчёта; пустой номер второй SIM исключает её из отчёта |
| Секунд до снятия трубки | Сколько ждать перед автоответом |
| Максимальная длительность записи | 0 — после сообщения сразу положить трубку |
| Секунд до сброса (исходящий) | Сколько «висеть» на исходящем звонке |
| mp3 для первой / второй SIM | Файл приветствия, выбирается системным диалогом |
| Начало сбора данных | С этого момента собираются SMS и звонки; изменение сбрасывает курсор |
| Хранить записей разговора | Старые записи удаляются автоматически |

Кнопки:

- **«Отправить сейчас»** — внеочередной обмен (заблокирована, пока есть несохранённые
  изменения);
- **«Запустить/Остановить фоновый процесс»** — то же, что снятие задачи в уведомлении;
- **«Запускать при включении телефона»** — доступно, когда процесс запущен.

## 6. Проверка без реального сервера

В репозитории есть тестовый сервер на Go (`docs/test-server/main.go`): печатает приходящие
отчёты и умеет возвращать команды.

```bash
cd docs/test-server
go run main.go -sim "+79001234567" -sms-to "+79007654321" -call-to "+79007654321"
```

В настройках приложения:

- URL обмена — `http://<адрес компьютера>:8080/exchange`;
- URL отчёта об исходящих — `http://<адрес компьютера>:8080/outgoing-report`;
- номер первой SIM — тот же, что в `-sim`.

Телефон и компьютер должны быть в одной сети. Нажатие «Отправить сейчас» покажет в логе
приложения отправленный JSON, а на компьютере — пришедший отчёт. Через 5 секунд после ответа
сервер вернёт команду отправить SMS, через 10 — команду позвонить.

## 7. Что проверить на телефоне

| Проверка | Как понять, что работает |
|---|---|
| Автоответ | Позвонить на SIM: через настроенные секунды трубка снимается |
| Слышимость приветствия | Абонент слышит mp3 (громкая связь + микрофон; прямой подмешки звука без root нет) |
| Запись ответа | В «Настройки» → «Записи разговоров» появляется файл, он открывается плеером |
| Запись во время звонка | Если запись пустая — в логах будет предупреждение об источнике звука |
| Отправка SMS | Нажатие команды сервера: SMS приходит адресату |
| Звонок с выбранной SIM | В журнале вызовов видна нужная SIM, иначе в логах предупреждение |
| Живучесть фона | Свернуть приложение, закрыть его из списка задач, подождать два интервала |

## 8. Известные ограничения

- Автоответ работает через публичный API `acceptRingingCall` с разрешением «Ответ на звонки»;
  на части прошивок он требует роль «Телефон по умолчанию». Приложение намеренно её не просит:
  собственного экранного интерфейса звонка нет, и роль сломала бы обычные звонки.
- Звук приветствия попадает в линию через громкую связь и микрофон: прямой подмешки в
  исходящий канал без root не существует.
- Запись делается с микрофона, поэтому в неё попадает и приветствие, и шум комнаты.
  Запись линии (`VOICE_CALL`) закрыта с Android 10.
- Программно положить трубку можно с Android 9 (`endCall`); на 8.0–8.1 звонок придётся
  завершить вручную.
- Номера SIM обычно недоступны для чтения: их нужно вписать в настройки, иначе ключа отчёта нет.
- Отчётов о доставке SMS приложение не отслеживает: успехом считается передача сообщения
  оператору.

## 9. Диагностика

Вкладка **«Логи»**: фильтр по категориям (служба, обмен, SMS, входящие и исходящие звонки),
поиск по тексту, разворот подробностей с JSON запроса и ответа, копирование в буфер.

Файлы приложения (`Android/data/ru.promcalc.phonegate/files` при доступе через файловый
менеджер):

| Файл | Содержимое |
|---|---|
| `logs/gateway-ГГГГ-ММ-ДД.jsonl` | журнал за день, хранится 7 дней |
| `tasks.json` | очередь задач от сервера |
| `outgoing.json` | журнал выполненных действий |
| `records/*.m4a` | записи ответов абонентов |
| `message-cache/*.mp3` | копии выбранных приветствий |
