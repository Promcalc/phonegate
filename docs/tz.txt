приложение должно запуститься при включении телефона в фоне (если есть установка в настройках) и проводить следующие действия:
- раз в опреденный интервал времени подключаться по указанному url и отправлять туда список номеров телефонов и времени звонков, полученных с момента предыдущеей отправки, список всех СМС с текстами, временем получения и номерами отправителей
- время предыдущей отправки должно сохраняться в системе для корректного продолжения работы после перезагрузки телефона
- при запуске приложения руками, должно октыться окно приложения и в нем я хотел бы видеть возможность видеть настройки и логи отправки данных
- после закрытия приложения фоновый процесс, если был запущен, то должен остаться запущенным

Настройки, которые хотелось бы видеть:
 - запускать ли фоновый процесс при включении телефона
 - кнопка запуска/остановки фонового процесса - запускает/останавливает фоновый процесс
 - интервал запросов (как вариант в секундах)
 - url запроса
 - номер телефона для первой sim карты
 - номер телефона для второй sim карты
 - количество сигналов при входящем звонке, после которых брать трубку и проигрывать файл сообщения (если есть возможность понять, количество гудков, если нет, то количество секунд после поступления звонка)
 - максимальная длительность записываемого сообщения при входящем звонке
 - количество сигналов при изходящем звонке, после которых класть трубку (если есть возможность понять, количество гудков, если нет, то количество секунд после начала звонка)
 - путь к mp3 файлу с сообщением для входящих звонков на номер телефона для первой sim
 - путь к mp3 файлу с сообщением для входящих звонков на номер телефона для второй sim

Псоле сохранения настроек, если фоновый процесс запущен, то надо его перезапустить с новыми настройками.
Настройки сохраняются при перезагрузке телефона.

Формат отправки данных на url:
- метод запроса POST
- content-type: json
- структура данных:
{
	"sim1_phone": {
		"sms": [
			{
				"time":"YYYY-mm-ddTHH:mm:ss+HH:mm",
				"text":"message text",
				"phone":"sender phone number"
			},
			...
		],
		"call": [
			{
				"time":"YYYY-mm-ddTHH:mm:ss+HH:mm",
				"text":"message text",
				"phone":"caller phone number",
				"duration": in_seconds
			},
			...
		]
	},
	"sim2_phone": {
	...
	}
}

Где:

sim1_phone - номер телефона из первой sim карты
sim2_phone - номер телефона из второй sim карты
sms - список полученных смс
call - список звонков
time - дата и время с временной зоной
phone - телефонный номер источника
text - текст смс или расшифровка голосового сообщения при звонке
duration - длительность сообщения при звонке

На начальном этапе нам не нужно расшифровывать голосовое сообщение в текст. Расшифровку будем добавлять позже. На начальном этапе в поле text для звонка пусть будет пустая строка.

При входящем звонке мы ждем количество гудков из настроек (или секунд). Если звонок за это время не сбросился, то снимаем трубкуи проигрываем сообщение из настроек, если оно есть в настройке для данной sim карты и записываем то, что нам наговорят голосом не дольше настройки времени записываемого сообщения. Если в настройке стоит 0, то после проигрывания сообщения кладем трубку. Если в настройке нет пути к mp3 файлу или файла нет, то после ожидания количества гудков или секунд сбрасываем звонок.

В ответ сервер присылает json структуру:

{
	"sim1_phone": {
		"sms": [
			{
				"time":"YYYY-mm-ddTHH:mm:ss+HH:mm",
				"text":"message text",
				"phone":"recipient phone number"
			},
			...
		],
		"call": [
			{
				"time":"YYYY-mm-ddTHH:mm:ss+HH:mm",
				"text":"message text",
				"phone":"recipient phone number"
			},
			...
		]
	},
	"sim2_phone": {
	...
	}
}

В этой структуре присутствуют для каждого номера список смс с тестом, временем отправки и телефоном адресата и список звонков, которые нужно совершить с номером и текстом сообщения.
При получении списка смс нужно отправить в указанное время с того номера, для которого список смс предназначен. Если время уже прошло, то отправить сразу.
При получении списка звонков нужно совершить звонки по номерам в указанное время и ожидать указанное в настройках количество гудков (или секунд), если трубку подняли то проговорить сообщение из поля text. Если время уже прошло, то произвести действие немедленно. На первом этапе ничего не проговариваем, просто кладем трубку, если на другом конце сняли трубку. 

Логи, которые хочется видеть на начальном этапе:
- время, адрес запроса, json данные запроса и ответа
- время, номер отправленного СМС и его текст
- время, номер исходящего звонка
